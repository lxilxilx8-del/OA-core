一个可自行部署的个人微信 AI 助手项目：微信消息接入、本地聊天归档、可管理记忆、文件资料库和有限度的主动聊天。

**版本：1.2.0 预览版。模型能力由外部模型服务提供，本项目不训练或附带模型。**

## 1.2.0 内核整理

- 多图按接收顺序合并，一轮统一读取，避免只保留最后一张。
- 原图保留8天，每10分钟检查清理；排队和处理中的任务会推迟清理。程序关闭期间不执行清理。
- 图片文字摘要带“模型生成”标记保存在历史中，原图删除后仍可检索；细节需要重发原图核对。
- 统一公开版与运行版的多图、缓存和记忆模块，提供中英文文档与独立测试。

## 功能

- 微信私聊文字、图片和文件接入，仅处理扫码绑定用户的消息。
- 按消息 ID 去重、连发消息合并、模型调用排队和超时处理。
- SQLite 保存普通聊天档案；模型每次只读有限近期消息及相关旧话。
- 个人记忆可分页查看、按编号纠正/遗忘，并可设置临时有效期。
- 公开信息搜索、文件总结/导出、个人资料库、按主题持续关注。
- 主动聊天默认关闭：每天最多2次，23:00～09:00免打扰，未回复上一条就不追发。
- Windows 安装与卸载入口；卸载可保留或删除本地数据。

聊天和资料默认存于使用者电脑，但回复时选用的内容仍会交给云端模型处理。详情见 [PRIVACY.md](PRIVACY.md)。

## Windows 使用

在理解上述接入限制后，可使用预览安装包：

1. 解压完整目录。
2. 双击 `一键安装小A.cmd`。需要 Windows 10/11 x64、联网环境；缺少 Python 时使用 winget 准备 Python 3.13。
3. 按提示使用自己的 Google 账号登录 AGY，再用自己的微信扫码绑定。首次授权不能代替使用者自动完成。
4. 安装完成后从桌面“XiaoA Core”启动。

程序安装在 `%LOCALAPPDATA%\XiaoACore`，新用户数据在该目录的 `data/`。源码目录不附带任何已登录账号、聊天数据库、私人图片或创作者的作息设置。

双击 `卸载小A.cmd`，或在 Windows 应用列表中卸载“小A内核版”。卸载不删除共享的 Python、AGY，也不处理安装目录之外的其他小A。

## 微信命令示例

| 命令 | 用途 |
|---|---|
| `助手帮助` | 功能与限额说明 |
| `记忆列表` / `记忆列表 2` | 分页查看个人事实 |
| `查看记忆 M12` | 查看指定记忆及来源 |
| `纠正记忆 M12：新内容` | 替代原记忆 |
| `忘记记忆 M12` | 不再在回答中使用该记忆及相关源对话；本机归档仍保留 |
| `记住7天：内容` | 保存临时记忆 |
| `回忆：关键词` | 本地历史检索 |
| `重置对话` | 开始新上下文，保留本机档案 |
| `关注：公开主题` | 添加定期关注 |
| `开启主动聊天` / `关闭主动聊天` | 管理主动开口 |

`M12` 是格式示例，实际编号以自己的记忆列表为准。

## 开发与验证

使用64位 Python 3.11～3.13，建议独立环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\test_uninstall.ps1
.\.venv\Scripts\python.exe tools\build_release.py
```

这些测试使用合成消息和模拟模型/微信调用，不需要登录真实账号。卸载测试只处理临时目录，并模拟进程与注册表操作。GitHub CI 在 Windows 上运行离线功能测试；未代表所有机器上的真实扫码登录都已验收。

打包工具仅使用 `release-files.json` 的文件白名单，生成 SHA-256 清单和 ZIP 到 `dist/`。新增公开源码时需明确更新白名单，不能将已运行的数据目录直接压缩上传。

## 已知边界

- 当前 AGY 接入有上述官方服务限制；接口、模型列表和微信服务变化可能影响使用。
- 缺少服务器消息 ID、处理途中崩溃或发送结果不明确时，不能保证绝对只执行一次；等待队列仍在内存中。
- “忘记”移出模型上下文，不是安全擦除本机归档或以前备份。
- 微信能否接受主动推送由服务端决定；后台模型分析和通知均有每日上限。
- 旧版本已经裁掉的聊天无法凭空恢复。当前记录可以迁移，之后普通聊天不再随提示窗口裁剪。
- 不含创作者的投资脚本、远程电脑控制、私人图标、表情包资源、语音或绘图模块。
